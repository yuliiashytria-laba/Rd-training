# 🎓 Рейтинг курсів Coursera

Streamlit-дашборд з AI-агентом (Gemini), який аналізує рейтинги курсів з бази `rd-training-course-db`.

## Що вміє

- **Огляд**: ключові метрики, точкова діаграма «кількість відгуків × середня оцінка» та поле, де можна поставити питання агенту.
- **Топ-10 / 10 найгірших**: таблиця рейтингу та саммері відгуків для кожного курсу.
- **Пошук курсу**: місце в рейтингу («#N з 254»), метрики та саммері відгуків обраного курсу.

## Метрики

| Метрика | Як рахується |
|---|---|
| Байєсова оцінка (основна) | `(n × avg + m × C) / (n + m)`, де `C` — загальне середнє всіх відгуків, `m` — 25-й перцентиль кількості відгуків на курс |
| Середнє ★ | `AVG(stars)` по відгуках курсу |
| Кількість відгуків | `COUNT(*)` по відгуках курсу |
| Частка 1–2★ | частка відгуків з оцінкою 1 або 2 |

Рейтинг будується лише для курсів, що мають відгуки в таблиці `reviews` (254 курси).
`review_score` з `dim_course` — це рейтинг спеціалізації, однаковий для всіх її курсів,
тому він показується лише як довідка.

Байєсове середнє використовується тому, що оцінки курсів дуже близькі (4.79–4.90 ★):
воно прибирає нічиї та не дає курсам з малою кількістю відгуків випадково потрапити в топ чи антитоп.

## Агент

Один простий агент на Gemini (`gemini-3.5-flash-lite` за замовчуванням):

1. **Саммері відгуків**: читає всі відгуки курсу й повертає висновок, «що хвалять» і «на що скаржаться» українською.
   Саммері кешуються у `summaries.json`, тому повторні перегляди миттєві. Кнопка «Оновити саммері» генерує нове.
2. **Відповіді на питання**: отримує таблицю рейтингу та готові саммері й відповідає лише на їх основі.
   Усі цифри рахує SQL, а не модель.

## Запуск локально

```bash
pip install -r requirements.txt
cp .env.example .env    # Windows: copy .env.example .env
# заповніть .env: DATABASE_URL, GEMINI_API_KEY
streamlit run app.py
```

## Деплой на Streamlit Community Cloud

1. Завантажте репозиторій на GitHub (без `.env`, він уже в `.gitignore`).
2. На [share.streamlit.io](https://share.streamlit.io) створіть застосунок з `app.py`.
3. У **Settings → Secrets** додайте:

```toml
DATABASE_URL = "postgresql://..."
GEMINI_API_KEY = "..."
GEMINI_MODEL = "gemini-3.5-flash-lite"
```

## Безпека

`.env`, `.streamlit/secrets.toml` і `summaries.json` додано в `.gitignore`.
Підключення до бази — read-only користувачем.
